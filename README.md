# Beijing Subway motion（地铁配线图 iOS 应用）

北京市轨道交通线路配置图，做成 iPhone 应用。中文名：地铁交路；英文名：Beijing Subway motion，版本 1.0.1（配线图数据 2.8.0）。

- 地图来源：[SierraQin/metro](https://github.com/SierraQin/metro)（CC0 1.0 协议），正式版 2.8.0（2026-07-14）
- 应用：一个 WKWebView 壳，里面是完全离线的地图网页——地图 SVG、PDF 和 JS 库都打在包里，不用联网、不用 VPN
- 功能：整张配线图，捏合缩放、拖动；原生 UITabBar 底栏（iOS 27 SDK；换乘 / 配线图 / 搜索 / 设置，SF Symbols 图标，选中地铁蓝 #003380；点底栏或在底栏上滑动切换，网页底栏已隐藏）；换乘页搜索按钮为液态玻璃（半透明蓝 + 磨砂 + 高光）；适配 iPhone Duo 折叠屏（窗口尺寸变化时地图自动重新适配，当前缩放/平移保持不变）；构建时优先选用最新的 iOS SDK 27.x（27.3/27.2/27.1/27.0），没有则用默认 Xcode；换乘页可选用时最少 / 换乘最少，并显示预计用时和到达时间（每站约 2 分钟，每次换乘约 5 分钟）；开屏为北京配线查询设计图；应用名 Beijing Subway motion，版本 1.0.1；车站搜索（中文、拼音、首字母，点车站定位到图上，420 个车站，来自地图 SVG 本身）；换乘（出发/到达可直接输入站名联想选站，点“出发/到达”可打开全部车站列表，26 条线、508 条边算最优路线，点一段在图上查看；搜索按钮蓝色）；深色模式（跟随系统，更多里可切浅色/深色）；横竖屏都全覆盖显示；底栏可点可左右滑动切换

## 打包

GitHub Actions（macOS）跑 `bash build.sh`：先把离线网页拼出来，再用 `swiftc` 编译 Swift 壳（不签名），打包成未签名的 IPA，侧载安装时用自己的 Apple ID 重新签名。
