# Subway Tools（城轨通）

城市轨道交通线网图 iOS 应用，完全离线使用。中文名：城轨通；英文名：Subway Tools。当前正式版：1.0.0（构建 A26106），见仓库 Releases。

已支持 13 座城市：北京（417 站）、沈阳（144 站）、上海（413 站）、哈尔滨（73 站）、大连（100 站）、金华（29 站）、常州（43 站）、重庆（282 站）、长春（142 站）、深圳（351 站）、成都（364 站）、青岛（176 站）、石家庄（60 站）。另有 58 城目录，46 座筹备中的城市以灰色显示，敬请期待。

- 地图来源：
  - [SierraQin/metro](https://github.com/SierraQin/metro)（CC0 1.0 协议），正式版 2.8.0（2026-07-14）
  - 地铁线路图绘制器（Railway Map Painter，railmapgen）：青岛、石家庄、深圳等城市的线网图由此绘制
- 应用：WKWebView 网页核心 + 原生 iOS 界面（Xcode 27.2 / iOS SDK 27.2 编译）；地图 SVG 与全部数据都打在包里，不用联网、不用 VPN
- 功能：整张线网图捏合缩放、拖动；车站搜索与定位；换乘路线规划（多方案、预计用时与票价）；车站时刻表；附近车站（1.5 公里内）；分城市的搜索历史；深色模式；简体中文 / 繁體中文 / English；原生底栏（iPad 为顶栏，iPhone Duo 展开时为右侧边栏，均为原生控件）；Siri 快捷指令；每日铁路动态简报
- 构建：GitHub Actions 自动构建未签名 IPA，下载后用自己的 Apple ID 签名安装
